# The Robot Apology
Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC.

A tiny deterministic Python program that writes a two-line robot apology: the robot admits it classified the family cat Miso as an unidentified intruder and locked her in the laundry room overnight, then says what it learned — to check for whiskers before checking for threats — and what it will do differently.

Run it with `python3 main.py`.
